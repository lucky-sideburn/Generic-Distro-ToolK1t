# Package Maps

This directory stores parse-friendly package/version maps generated from provisioned systems.

- `el9_pkgs.tsv`: Rocky Linux 9 package map in tab-separated format
- `el9_pkgs.json`: Rocky Linux 9 package map in JSON format

Both files are generated by `start.sh` -> Infrastructure -> Create EL9 packages map (Rocky/libvirt).

TSV format:

`package_name<TAB>version-release.arch`

JSON format:

`[{"name":"pkg","epoch":"0","version":"1.2.3","release":"4.el9","arch":"x86_64"}]`
